# Portfolio Website

A modern, responsive portfolio website built with React 18, Vite, and Tailwind CSS. Inspired by clean, minimal design with smooth animations and professional styling.

## ✨ Features

- **Responsive Design**: Looks great on all devices (mobile, tablet, desktop)
- **Modern Tech Stack**: React 18, Vite, Tailwind CSS
- **Smooth Animations**: CSS animations and transitions for enhanced UX
- **Clean & Professional**: Minimal design focused on content
- **Fast Performance**: Optimized with Vite for lightning-fast development and builds
- **Accessible**: Built with accessibility best practices in mind

## 🚀 Sections

- ✅ **Hero Section**: Eye-catching introduction with call-to-action buttons  
- ✅ **About Section**: Personal info with skills and profile image
- ✅ **Projects Section**: Portfolio showcase with detailed project cards
- ✅ **Contact Section**: Contact form with validation and social links
- ✅ **Footer**: Simple, responsive footer with navigation

## 🛠️ Tech Stack

- **Frontend**: React 18, Vite
- **Styling**: Tailwind CSS 3.4.17
- **Build Tool**: Vite
- **Linting**: ESLint
- **Fonts**: Inter (Google Fonts)

## 📦 Installation & Setup

1. **Clone or download the project files**

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```

4. **Open your browser** and navigate to `http://localhost:5173`

## 🔧 Available Scripts

- `npm run dev` - Starts the development server
- `npm run build` - Creates a production build
- `npm run preview` - Preview the production build locally
- `npm run lint` - Run ESLint for code quality checks

## 🎨 Customization

### Colors
The color scheme is defined in `tailwind.config.js`. Current colors:
- **Primary**: Blue tones (#0ea5e9 and variants)
- **Secondary**: Gray tones (#64748b and variants)

### Content
Update the following files to customize content:
- `src/components/Hero.jsx` - Main headline and intro
- `src/components/About.jsx` - About section content and skills
- `src/components/Projects.jsx` - Project portfolio items
- `src/components/Contact.jsx` - Contact information

### Styling
- Global styles: `src/index.css`
- Component-specific styling: Individual component files
- Tailwind config: `tailwind.config.js`
